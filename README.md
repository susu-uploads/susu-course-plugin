# SUSU Courses

Codex plugin для работы с самостоятельными репозиториями учебных курсов по [susu-course-template](https://github.com/susu-uploads/susu-course-template). Содержит два skill:

- [`susu-course-guidelines`](skills/susu-course-guidelines/SKILL.md) — соглашения о структуре, наименованиях, метаданных, хранении материалов и работе с Git, а также порядок внесения и проверки изменений.
- [`susu-course-export`](skills/susu-course-export/SKILL.md) — первичная и повторная выгрузка курса из Moodle с применением гайдлайнов.

Заготовки файлов остаются в отдельном проекте шаблона. Гайдлайны определяют формат репозитория и методологию работы с ним; export описывает получение и распределение учебного содержания. Методология охватывает работу с файлами курса, сохраняя существующие решения. Подготовка решений, ноутбуков и отчётов в эти skills не входит.

## Подключение

Добавьте репозиторий как источник плагинов:

```sh
codex plugin marketplace add susu-uploads/susu-course-plugin --ref main
codex plugin add susu-course-plugin@susu-course-plugins
```

Для проверки локальной версии используйте вместо адреса GitHub путь к каталогу этого проекта:

```sh
codex plugin marketplace add /path/to/susu-course-plugin
```

Установите **SUSU Courses** из источника **SUSU Course Plugins** в каталоге плагинов Codex. Плагин содержит инструкции и не требует подключения MCP-сервера или стороннего аккаунта; доступ к Moodle нужен только для выбранной выгрузки.

## Примеры запросов

- «Используй `$susu-course-guidelines`: проверь структуру курса, frontmatter, Git LFS и правила игнорирования».
- «Используй `$susu-course-guidelines`: приведи этот курс к структуре шаблона, сохрани материалы и решения».
- «Используй `$susu-course-export`: создай репозиторий курса по шаблону; источник Moodle — …, каталог назначения — …».
- «Используй `$susu-course-export`: обнови `COURSE.md` и `TASK.md` по Moodle, сохрани вложения и решения».

При обычной правке или проверке проекта применяются гайдлайны. При выгрузке Moodle export сначала читает гайдлайны из соседнего каталога; оба skill поставляются одним плагином.

Выгрузка сохраняет исходный язык, формулировки, порядок и ссылки. Источник задания находится в frontmatter; тело `TASK.md` содержит только описание из Moodle. Коммиты и публикация выполняются по запросу пользователя.

Формат упаковки и подключение источников описаны в [официальной документации OpenAI](https://developers.openai.com/plugins/build/plugins).
