# SUSU Courses

Codex plugin для создания, выгрузки и сопровождения самостоятельных репозиториев учебных курсов. Содержит один skill — `susu-course`.

Заготовки файлов хранятся отдельно в [susu-course-template](https://github.com/susu-uploads/susu-course-template). Плагин определяет порядок работы: создание курса, перенос учебного содержания Moodle, обновление карточек и проверку структуры, метаданных, Git LFS и правил игнорирования.

## Подключение

Добавьте репозиторий как источник плагинов:

```sh
codex plugin marketplace add susu-uploads/susu-course-plugin --ref main
codex plugin add susu-course-plugin@susu-course-plugins
```

Для проверки локальной версии используйте вместо адреса GitHub путь к каталогу этого проекта:

```sh
codex plugin marketplace add /path/to/susu-course-plugin
```

Установите **SUSU Courses** из источника **SUSU Course Plugins** в каталоге плагинов Codex. Плагин содержит инструкции и не требует подключения MCP-сервера или стороннего аккаунта; доступ к Moodle нужен только для выбранной выгрузки.

## Примеры запросов

- «Используй skill `susu-course`: создай репозиторий курса по шаблону; источник Moodle — …»
- «Обнови `COURSE.md` и `TASK.md` по Moodle, сохрани вложения и решения».
- «Проверь структуру курса, frontmatter, Git LFS и правила игнорирования».
- «Приведи этот курс к структуре самостоятельного репозитория».

Выгрузка сохраняет исходный язык, формулировки, порядок и ссылки. Источник задания находится в frontmatter; тело `TASK.md` содержит только описание из Moodle. Коммиты, вынос из монорепы и публикация выполняются в пределах запроса пользователя.

Формат упаковки и подключение источников описаны в [официальной документации OpenAI](https://developers.openai.com/plugins/build/plugins).
